Purpose

This document defines the sender and beneficiary data fields ZakaPay captures inside the WhatsApp flow to satisfy Travel Rule and FICA/RBZ compliance requirements for the SA to ZW remittance corridor. ZakaPay uses AI-native intent parsing to capture these fields conversationally inside WhatsApp. No app download. No web forms. No friction.

Key Design Principles

  • All data captured conversationally inside WhatsApp
  • No app download required from sender or beneficiary
  • Selfie and ID captured via WhatsApp image message
  • AI parser extracts fields from natural text input
  • Compliance checks run in real-time before transaction submission
  • Full audit trail exportable for SARB sandbox reporting
  • Two-tier schema: minimal pilot set for speed, full set for production
